Data Types in C

Each variable in C has an associated data type. It specifies the type of data that the variable can store like integer, character, floating, double, etc.

C is a statically typed language where each variable's type must be specified at the time of declaration and once specified, it cannot be changed.

Types of Data Types in C

  • Basic Data Types: int, float, double, char
  • Derived Data Types: array, pointer, function
  • User Defined Data Types: struct, union, enum

Example Program

#include <stdio.h>

int main() {

    // integer
    int age = 20;

    // floating-point
    float height = 5.7;

    // double-precision
    double pi = 3.14159;

    // character
    char grade = 'A';

    printf("Age: %d\n", age);
    printf("Height: %.1f\n", height);
    printf("Pi: %.5lf\n", pi);
    printf("Grade: %c\n", grade);

    return 0;
}

Output

Age: 20
Height: 5.7
Pi: 3.14159
Grade: A
Note: The exact size and range of C data types depend on the compiler and system architecture. The sizes mentioned are typical for most systems.

Integer Data Type

  • Stores whole numbers (positive, negative, or zero)
  • Declared using int keyword
  • Size: typically 4 bytes
  • Range: -2,147,483,648 to 2,147,483,647
  • Format specifier: %d
